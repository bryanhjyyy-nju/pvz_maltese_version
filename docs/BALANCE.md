波间隔从一波开始生成时计算。波内每只间隔 0.9 秒。最后一波先提示 1.8 秒，再生成第一只。
开局准备时间在镜头、铺草、准备提示与教程全部完成后才开始。

前三关的可种植排数分别为 1、3、5。第二关保留正中一排，第三关保留中间三排，只为新增的排数播放铺草动画。
第一关教程把爱心补足到 100，实际种植歌唱小白消耗 100，示范收集增加 25；已种的小白与剩余资源保留到战斗。表中 50 为关卡配置的基准资源。
第二关的三株铲子练习小白免费放置，全部铲除才开始准备倒计时；资源保持表中的 50。
未开放的格子由立体金砖覆盖；新增排的金砖从左向右逐块下落。金砖只负责视觉展示，可种植范围仍由地图配置控制。
天空爱心下降时间为 8 秒，从卡片栏下方的画面内出现（逻辑坐标 y=140）；生成间隔为每 12–15 秒一颗、每颗 25 爱心。可收集爱心采用 108×100 的卡通图案，正常显示完全不透明；小白产出的爱心仍下落 3 秒。下落途中可以收集；落地后停留 3.5 秒，用 1 秒闪烁两次，再用 1 秒淡出，闪烁期间仍可收集。

双唱小白每 1.6 秒开始一组两发连射，两发相隔 0.18 秒，每发伤害 30；两组起点间隔与歌唱小白相同。满心小白每 12 秒同时产出两颗爱心，总值 50，产出周期与爱心小白相同。

冲锋小白消耗 125 爱心，卡片冷却 30 秒；移动速度仍为 100 像素/秒，碰撞伤害仍为 2000。它开始移动后释放原草格，允许在那里种下新小白；冲锋单位仍属于战场上的同排单位，离场或被移除时不会删除原格的新小白。坚盾小白生命值为 4000。

## 权重与抽选

普通金毛权重 1；吉他金毛权重 3，具有更高生命和远程能力；冲刺金毛权重 4，具有更高移速和近战伤害。
抽选前排除尚未开放或超过剩余预算的类型。符合条件的类型使用相对概率 1、0.20、0.08，逐只扣除权重，直到剩余预算为 0。第 1、9、10 关保持每波精确预算；第 2–8 关使用以下渐进安排：

| 关卡 | 按波排列的实际数量 |
| --- | --- |
| 2 | 1、1、2、3 |
| 3 | 1、1、2、3、4 |
| 4 | 1、2、1 或 3、4、5 |
| 5 | 1、2、1 或 3、1 或 3、4、5 |
| 6 | 1、3、2 或 4、2 或 4、5、6 |
| 7 | 1、3、1 / 2 / 4、1 / 2 / 4、5、6 |
| 8 | 1、3、1 / 2 / 4、1 / 2 / 4、1 / 2 / 4、5、6 |

前两波只出现普通金毛。中间波次保持原有权重抽选；最后两波先按原有预算抽选，保留其中的强敌，再补入普通金毛并打乱顺序，确保倒数第二波比之前任何一波数量更多，最后一波再多一只。由于强敌组合不同，补入普通金毛后实际总权重存在表中的小幅变化。完整计划在战斗前生成并统计总数，胜利判断使用实际数量。

## 后期调整

旧第 8 关吉他出现概率达 75%，第 10 关最多 50 只敌人且允许额外成批刷出，随机组合使压力波动很大。
新第 8–10 关降低总威胁、限制强敌抽选概率、延长波间隔，并增加开局资源和准备时间。每波优先分配到敌人权重较低的排，减少同排强敌堆叠。
吉他金毛射击间隔由 4 秒缩短为 2 秒，频率翻倍，单发伤害仍为 15。
吉他金毛生命 800 → 480，远程伤害 15、间隔 2 秒；近战仍为 60 / 0.5 秒。金色双音符每 2 秒沿本排向前直线飞行，不受目标距离限制，遇到本排的小白后命中并消失；贴身时只啃食。发射和命中分别播放音效。远程伤害不会触发跳舞小白的近战反弹或招财小白的近战击退。

## 验证与后续调节

### 无尽模式

第十关通关或使用全解锁后开放，使用第十关的初始资源、五排草坪与全部八张小白卡。
第 N 波预算为 `4 + 2N`，三个敌人类型按共用概率填满预算；每只仍间隔 0.9 秒，最后一只死亡动画完成后准备 6 秒再进入下一波。
敌人生命乘以 `1 + 0.08(N-1)`，近战攻击乘以 `1 + 0.025(N-1)`，移速乘以 `1 + 0.01(N-1)`，数值按实体整数属性取整。吉他远程伤害随攻击属性提升。
每波开始记录最高到达波数；没有最终波或胜利结算，只在失败后结束本轮。重新启动程序后，未完成的无尽游戏从当前波重新开局。

自动化验证原有波次的精确预算、第 2–8 关前两波减压与最后两波数量递增、解锁范围、实际排队刷出及 10 关结算；固定种子抽样验证普通最多、吉他其次、冲刺最少。
这些检查验证规则与数值，难度体感仍需实际游玩。进一步调整时优先改每波预算、波数、间隔和开局爱心，避免重新引入随机额外刷怪。
