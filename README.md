# 小白大战小金毛

基于 Qt Widgets / Graphics View 的塔防小游戏，包含 10 个关卡、8 种小白和 3 种金毛。

## 编译与运行

推荐使用项目原有的 **Qt 5.15.2 + MinGW 8.1（64 位）**，需要 Widgets、Multimedia；编译测试目标另需 Qt Test。
代码使用兼容 Qt 5 / Qt 6 的接口；本次完整版本在 Qt 5.15.2 验证。本机 Qt 6.8.3 缺少 Multimedia，不能直接构建完整声音版本。

在项目目录运行 PowerShell：

```powershell
# 编译并复制 Qt 运行库，可直接双击运行生成的 exe
.\tools\build.ps1 -Deploy

# 运行自动化测试，生成测试报告和界面截图
.\tools\build.ps1 -Test
```

可直接运行的完整目录：`build-release/dist/PvZ_demo.exe`。只运行编译指令的输出是 `build-release/release/PvZ_demo.exe`。
安装位置不同时，用 `-QtRoot` 和 `-CompilerRoot` 指定对应工具链。也可以在 Qt Creator 打开 `PvZ_demo.pro` 编译运行。

## 操作

- 首页标题和开始 / 退出按钮由代码绘制；黄色按钮黑字，点击开始进入选关。
- 左键选择植物卡，再点击空格子种植；点击爱心收集资源。
- 点击草坪上方的铲子槽，或按 R：拿起 / 放下铲子；拿起后左键点击植物即可铲除。
- Esc 或鼠标右键：取消植物选择 / 铲子模式。
- 空格或侧边按钮：打开暂停菜单 / 继续。菜单可继续游戏、返回主菜单、查看图鉴和调整声音；Esc 也可关闭暂停菜单并继续。
- 暂停时移动、攻击、产出、刷怪、弹丸、受击 / 啃食 / 死亡动画和卡片冷却都停止；长按空格不会反复切换。
- 首页、选关页和战斗侧栏可查看植物 / 僵尸图鉴。战斗中查看图鉴或调整声音时会自动暂停。
- 声音设置可分别调节 BGM 和音效，拖到 0 即静音，设置自动保存。

## 存档规则

- 进入关卡时自动记录该关；失败或中途退出后，“继续游戏”从该关开局。
- 胜利后自动记录下一关；第 10 关通关后继续按钮指向第 10 关，选关页显示全部通关。
- 记录最高已通关关卡，重玩旧关不会降低该记录。原有自由选关保留。
- 保存的是**关卡进度**，不保存战场上的植物、敌人、爱心或计时器。
- 存档文件为 `QStandardPaths::AppDataLocation/progress.json`，Windows 通常位于 `%APPDATA%/DogGarden/PvZ_demo/progress.json`。
- 使用 `QSaveFile` 原子替换，避免写入中断留下半个 JSON；读取时验证版本和关卡范围。损坏存档会提示，重新选关可开始并写入新存档。
- 音量由 `QSettings` 单独存储。测试使用临时目录隔离音量和进度数据。

## 代码导览

| 文件 / 模块 | 职责 |
| --- | --- |
| `gamecatalog.*` | 植物、敌人数值、图片、技能说明和 10 关刷怪配置；战斗与图鉴共用 |
| `mainscene.*` / `chooselevelscene.*` | 首页、选关、继续游戏和关卡存档衔接 |
| `playscene.*` | 游戏窗口、植物卡栏、资源显示、暂停和弹窗 |
| `mygamescene.*` | 草坪布局、计时器、刷怪、植物工厂与放置、输入、胜负结算 |
| `gamepause.*` | 保存运行中的计时器 / 动画状态，恢复剩余时间；兼顾连续暂停 |
| `pausedialog.*` / `gameui.*` | 暂停菜单与共用卡通配色、木框、按钮样式 |
| `waveplanner.*` | 生成每波固定权重的敌人组合，控制强敌稀有度 |
| `enemyprojectile.*` / `combateffect.*` | 金色双音符弹丸与啃食、受击、种植 / 铲除粒子 |
| `gameartwork.*` | 可缩放的首页描边艺术字、笑脸铲子和铲子槽 |
| `progressstore.*` | 版本化 JSON 进度、边界验证和原子写入 |
| `almanacdialog.*` | 动画图鉴卡片和技能 / 数值展示 |
| `audiomanager.*` | 菜单 / 战斗音乐切换、音效复用、音量持久化 |
| `whitedogs.*` / 各植物类 / `yellowdogs.*` | 单位行为和碰撞 |
| `tests/test_game.cpp` | 存档、地图边界、音频加载、种植、暂停恢复、各关胜负、截图检查 |

场景用植物指针表作为格子占用的唯一依据。场景内实体同时加入 Graphics Scene 和 QObject 所有权树，退出时由 Qt 回收；移除战斗对象使用 `deleteLater()`，避免在对象自己的信号调用栈里销毁它。
当前保持单个战斗窗口；`Card` 的共享交互状态仍按这一前提设计。

## 音频与资源

新增的 `Media/*.wav` 是本项目用标准库合成的原创音乐和提示音，包含菜单 / 战斗循环音乐，以及暂停、种植、收集、射击、受击、啃食、死亡、铲子拿起 / 放下、铲除、胜负等音效，不依赖 MP3 解码器。
可用以下命令重新生成：

```powershell
python tools/generate_audio.py
```

原有图片和 MP3 文件保留。新增音频通过 `res.qrc` 打包，程序不依赖当前工作目录。
木框和星星来自 [Kenney UI Pack — Adventure](https://kenney.nl/assets/ui-pack-adventure)，许可为 CC0，来源和许可保存在 `Image/ui/`。

## 战斗与平衡

- 吉他金毛生命为 480，近战每 0.5 秒造成 60 伤害；每 4 秒沿本排向前发射金色双音符（无需前方已有植物），每发造成 15 伤害。贴身时只啃食；弹丸会被本排路径上的小白挡住。发射和命中有各自的音效。
- 敌人受击闪光，啃食时摇动并产生碎屑，死亡时旋转倒地、淡出。死亡开始后立即退出碰撞和攻击，动画播放完后计入击败数，最后一只的动画结束后胜利。
- 普通 / 吉他 / 冲刺敌人的权重为 1 / 3 / 4。每波精确填满关卡预算，可抽选的类型使用 1 : 0.20 : 0.08 的相对概率；吉他从第 4 关、冲刺从第 7 关加入。
- 同波每 0.9 秒生成一只，优先分配到敌人负担较低的排。第 8–10 关总权重分别为 28 / 35 / 40，开局有 100 爱心及 25–28 秒准备时间；详见 `docs/BALANCE.md`。
- 天空爱心每 3.5–4.5 秒生成一颗，修复了旧逻辑一次生成两颗的问题，并保持接近原来的平均资源供给。

## 验证范围

本轮 Qt 5.15.2 Release 测试结果：31 通过、0 失败；截图包括菜单、植物 / 僵尸图鉴、暂停、声音设置、金色音符 / 死亡和啃食效果。
完整分发目录已在 PATH 不含 Qt / MinGW 安装目录的环境中启动，确认使用目录内的 Qt 运行库、Windows 平台、GIF / JPEG 与音频插件。

自动化覆盖 10 关的敌人上限、胜利结算、防重复击杀，失败后停止活动，实际鼠标种植、暂停时位置不变及恢复后继续移动、计时器剩余时间和连续暂停；另覆盖存档损坏 / 写入失败、资源加载与界面截图。
测试还覆盖空格暂停菜单和主菜单返回、图鉴关闭后保持暂停、鼠标铲子、由吉他计时器自动发射、无目标时向前射击、实际金色音符碰撞伤害、近战与远程互斥、死亡停止攻击、受击 / 啃食 / 死亡和弹丸的暂停恢复；用 5,000 个固定种子关卡计划校验每波预算、解锁和强敌稀有度。
音频测试确认 18 个 WAV（2 首音乐与 16 个音效资源）都能被 Qt 解码加载；实际扬声器音量和听感仍取决于本机输出设备。
