# 小白大战小金毛

基于 Qt Widgets / Graphics View 的塔防小游戏，包含 10 个关卡、8 种小白和 3 种金毛。

## 编译与运行

推荐使用项目原有的 **Qt 5.15.2 + MinGW 8.1（64 位）**，需要 Widgets、Multimedia；编译测试目标另需 Qt Test。
代码使用兼容 Qt 5 / Qt 6 的接口；本次完整版本在 Qt 5.15.2 验证。本机 Qt 6.8.3 缺少 Multimedia，不能直接构建完整声音版本。

在项目目录运行 PowerShell：

```powershell
# 编译并复制 Qt 运行库，可直接双击运行生成的 exe
.\tools\build.ps1 -Deploy

# 运行自动化测试，生成测试报告和界面截图
.\tools\build.ps1 -Test
```

可直接运行的完整目录：`build-release/dist/PvZ_demo.exe`。只运行编译指令的输出是 `build-release/release/PvZ_demo.exe`。
安装位置不同时，用 `-QtRoot` 和 `-CompilerRoot` 指定对应工具链。也可以在 Qt Creator 打开 `PvZ_demo.pro` 编译运行。

## 操作

- 首页有“选择关卡”“继续游戏”“退出游戏”“小白 / 金毛图鉴”四个相同尺寸的黄色卡通按钮。未结束的关卡才可继续；通关或失败后继续按钮变灰。
- 选关按钮为卡通圆角方块，关卡文字和按钮随窗口一起等比例缩放。
- 左键选择小白卡，再点击空格子种植；点击爱心收集资源。
- 第一关没有铲子图标或功能，第二关起解锁。点击铲子槽，或按 R：拿起 / 放下；拿起后左键点击小白即可铲除。
- 鼠标右键：取消小白选择 / 铲子模式。Esc 只退出全屏，窗口模式下无额外作用。
- 空格或侧边按钮：打开暂停菜单 / 继续。菜单可继续游戏、重新开始本局、返回主菜单、查看图鉴和调整声音。重开会清空当前战场，从本关开场开始；无尽模式从第一波重开，已解锁关卡和最高纪录保留。
- 暂停时移动、攻击、产出、刷怪、弹丸、受击 / 啃食 / 死亡动画和卡片冷却都停止；长按空格不会反复切换。
- 暂停不会取消小白选择或铲子模式。继续后可直接种植或铲除；暂停后返回首页、查看图鉴或调整窗口大小也保留选择。
- H：独立开关小白头顶的实时血量；J：独立开关金毛头顶的实时血量。默认关闭，开启后新生成的单位也会显示，数字随受伤立即更新。
- F11 或“全屏”按钮：进入 / 退出全屏，首页、选关、战斗页都支持；跨页面保持当前模式。画面等比例缩放，空余区域留边。
- 标题栏最大化按钮从首次启动即可使用；最大化后点击“还原窗口”恢复原位置和大小。卡槽、卡片边框、小白图标、费用数字和种植预览同步缩放。
- 首页、选关和战斗在同一个窗口内切换。战斗中通过暂停菜单返回主菜单，再次继续时先显示暂停界面，战场保持原样。窗口右上角 × 或首页“退出游戏”直接退出应用。
- 暂停弹窗内也能使用 H / J / F11，切换不会解除暂停。
- 首页、选关页和战斗侧栏可查看小白 / 金毛图鉴。战斗中查看图鉴或调整声音时会自动暂停。
- 首页右上角的喇叭图标打开声音设置，可分别调节 BGM 和音效，拖到 0 即静音，设置自动保存。首页与选关的全屏按钮位于左上角；选关右上角使用原来的箭头返回。
- 小白卡牌在冷却时最暗，遮罩像窗帘一样向上收起；冷却结束但爱心不足时保持中等亮度。只有冷却结束且资源足够时卡牌最亮、爱心为红色，其余状态爱心为灰色。

## 开场、草坪与教程

- 每关先平滑右移镜头，展示本关可出现的金毛，再移回草坪。预览使用刷怪共用的 1 : 0.20 : 0.08 概率配置折算少量展示数量，并按正式战斗的原图尺寸与各类型缩放比例在右侧马路上随机排布，不加框或说明文字；这些装饰角色不会攻击或计入胜负。
- 第一关从空地铺出正中间一排；第二关保留中间一排并铺出相邻两排；第三关保留中间三排，只给最上、最下两排补草皮。第一、二关的其余空地不能种植。第三关铺完后与后续关卡的五排草坪一致。
- 尚未开放的格子铺着立体金砖，带有金色顶面、侧面、倒角和阴影。开场从左向右逐块下落露出草坪；已铺好的排保持完整，不能种植的排保留金砖。镜头与动画结束后，中央以红字黑边显示“准备迎接小金毛的进击！”，配合缩放、抖动、淡出和冲击音效。
- 第一关在准备文字消失后进入操作教程：补足到 100 爱心，种下一株歌唱小白；点击不会超时消失的示范爱心，收集 25 爱心；实际体验暂停与图鉴后，点击完成教程。练习种下的小白与剩余爱心会保留到战斗。
- 第二关免费放置三株歌唱小白，介绍铲子与右键取消。必须实际铲除三株才开始战斗；铲除不扣费，也不返还爱心。
- 开场与教程期间，战斗、天空爱心、刷怪和卡片冷却不计时。完成后才开始该关原有的准备时间。重玩或继续第一、二关时也会重走教程。
- 最后一波在生成前显示“最后一波小金毛即将来袭！”并播放独立警示音效，等待 1.8 秒后生成首只金毛。提示只绘制中央文字，不改变背景颜色，也不拦截鼠标；显示期间可以继续种植、收集和铲除。暂停会同时冻结文字动画和这段等待。

## 通关、存档与无尽模式

- 新存档只开放第一关；通关后逐关开放后续关卡。第 1–7 关胜利后播放胜利音乐、逐渐亮出下一关的新小白卡，并显示放射光芒。第 8–10 关为挑战关，胜利展示奖杯。
- 胜利动画结束后，第 1–9 关可以选择“返回选关”或“下一关”；下一关直接进入已解锁关卡的开场和教程。第十关保留返回选关。
- 失败时战场冻结，画面逐渐变黑，留下围住到达左侧的小金毛的聚光圈；随后显示“小白输给了小金毛！”、播放失败音效，自动返回选关。
- 首页“存档管理”可清空进度、当前游戏及无尽纪录，恢复为新存档；也可以一键开放全部关卡与无尽模式。音量设置独立保留。
- 进入关卡自动记录未完成状态。当前程序内暂停后返回首页会保留小白、敌人、爱心、动画和计时器；继续时保持暂停，手动继续才恢复。
- 关闭程序后保存的是关卡检查点：下次继续会从该关的开场重新开始，并先显示暂停菜单。第一、二关会重新进行教程。磁盘存档不包含整个战场快照。
- 第十关通关后，主菜单在选择关卡上方显示“开始无尽模式”，所有小白与五排草坪可用。每波威胁预算、生命、攻击和移速逐步增加；清完一波后准备 6 秒再来下一波，没有最终波或通关结算。
- 开始无尽后，暂停返回首页会显示“继续无尽模式”；失败后恢复为“开始无尽模式”。进入每波立即保存已到达的最高波数，首页显示纪录。关闭程序后从未结束的当前波检查点重新开局，并先暂停。
- 记录最高已通关关卡，重玩旧关不会降低解锁进度或无尽纪录。选择新的关卡会替换暂停中的旧游戏。
- 存档文件为 `QStandardPaths::AppDataLocation/progress.json`，Windows 通常位于 `%APPDATA%/DogGarden/PvZ_demo/progress.json`。
- 使用 `QSaveFile` 原子替换，读取时验证版本、关卡范围和解锁 / 未完成状态。支持旧版本进度迁移；损坏存档回退到第一关，重新开局可写入正常存档。
- 音量由 `QSettings` 单独存储。测试使用临时目录隔离音量和进度数据。

场景用小白指针表记录格子占用，同时按排维护仍在战场上的单位。冲锋小白开始移动后释放原格，但保留在战斗列表中，仍能攻击、被攻击和显示血量；清理按单位身份进行，避免它离场时误删原格上后来种下的小白。实体同时加入 Graphics Scene 和 QObject 所有权树，退出时由 Qt 回收；移除使用 `deleteLater()`，避免在对象自己的信号调用栈里销毁它。
主窗口最多持有一个战斗页面；未结束的战斗在暂停返回首页时保留。结算后返回或选择另一关时，先停止旧页面的计时器、动画和场景事件，再延后销毁。`Card` 的共享交互状态仍按单个活动战斗的前提设计。

## 音频与资源

新增的 `Media/*.wav` 是本项目用标准库合成的原创音乐和提示音，包含菜单 / 战斗循环音乐，以及暂停、种植、收集、射击、受击、啃食、死亡、铲子拿起 / 放下、铲除、胜负、开场冲击和最后一波警示等音效，不依赖 MP3 解码器。
可用以下命令重新生成：

```powershell
python tools/generate_audio.py
```

原有图片和 MP3 文件保留。新增音频通过 `res.qrc` 打包，程序不依赖当前工作目录。
木框和星星来自 [Kenney UI Pack — Adventure](https://kenney.nl/assets/ui-pack-adventure)，许可为 CC0，来源和许可保存在 `Image/ui/`。

## 战斗与平衡

- 吉他金毛生命为 480，近战每 0.5 秒造成 60 伤害；每 2 秒沿本排向前发射金色双音符（无需前方已有小白），每发造成 15 伤害。贴身时只啃食；弹丸会被本排路径上的小白挡住。发射和命中有各自的音效。
- 敌人受击闪光，啃食时摇动并产生碎屑，死亡时旋转倒地、淡出。死亡开始后立即退出碰撞和攻击，动画播放完后计入击败数，最后一只的动画结束后胜利。
- 普通 / 吉他 / 冲刺敌人的权重为 1 / 3 / 5，抽选相对概率为 1 : 0.20 : 0.08；吉他从第 4 关、冲刺从第 7 关加入。第 2–8 关第一波只有一只普通金毛，第二波为基础权重减一只普通金毛；中间波次保持原有预算，最后两波抽选后补足普通金毛，保证最后一波数量最多。第 7、8 关最后两波抽选预算为 5，数量仍为 5、6 只。第二关按四波 1、1、2、3 只安排。
- 冲刺金毛基础生命为 450；血量严格低于一半时，移速立即提升到初始速度的 1.5 倍，普通关卡为 60–73.5 像素/秒。后续伤害不会叠加加速，无尽模式按强化后的初始生命和移速计算；图鉴同步说明。
- 同波每 0.9 秒生成一只，优先分配到敌人负担较低的排。第 8 关总权重为 27–35，第 9、10 关仍为 35、40；开局有 100 爱心及 25–28 秒准备时间。各波数量详见 `docs/BALANCE.md`。
- 双唱小白与歌唱小白都每 1.6 秒开始射击；双唱每次连发两发，两发相隔 0.18 秒。满心小白与爱心小白都每 12 秒产出；满心每次同时产出两颗，左右错开方便分别收集。图鉴与卡片提示同步显示这些数值。
- 冲锋小白消耗 125 爱心、冷却 30 秒，开始移动后原草格可重新种植；离场不会影响原格的新小白。坚盾小白生命值为 4000。
- 可收集爱心使用 108×100 的粉红卡通笑脸，正常显示时完全不透明。落地后停留 3.5 秒，再用 1 秒闪烁两次，此时仍可收集；随后用 1 秒淡出消失。暂停也会冻结闪烁，收集会立即停止闪烁。
- 天空爱心每 12–15 秒生成一颗，从画面内卡片栏下方（逻辑坐标 y=140）出现，下降时间为 8 秒；全屏留边时不会从黑边掉下。小白产出的爱心仍为 3 秒。下落过程中点击即可开始 0.8 秒的收集动画，每颗可收集 25 爱心。

## 性能优化与测量

- 战场使用区域重绘，动画变化只更新受影响的位置；死亡动画的绘制范围覆盖旋转后的整个角色。
- 卡片缓存完整卡面和灰色爱心版本，冷却时只绘制遮罩；角色共用已缩放的 GIF 帧和可见轮廓，同时保留各自的动画时钟。缩放帧缓存最多占用 32 MiB。
- 碰撞只检查同排战斗单位，跳过背景、金砖和装饰。音符用一段直线动画飞到画面外，避免每 0.1 秒重建动画；速度和伤害保持原有数值。

同一台电脑、Qt 5.15.2 Release / Windows 下的固定场景测量：

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 8 张卡片合计重绘 1600 次 | 110 ms | 30 ms |
| 32 只金毛合计更新 2560 帧，开启血量 | 774 ms | 277 ms |
| 32 只移动金毛，每次重绘占视口的平均面积 | 97.50% | 8.98% |

以上是固定工作量的测量，实际帧率受窗口大小、战场单位数量和电脑性能影响。测量源码为 `tests/benchmark_game.cpp`；报告位于 `build-qt5-tests/benchmark-before.txt` 和 `benchmark-after.txt`。

qmake ..\pvz_benchmarks.pro 'CONFIG+=release' 'CONFIG-=debug'
mingw32-make -j4
.\release\pvz_benchmarks.exe -platform windows -o benchmark-results.txt,txt
